🧭 API 地址填写规则（8000 转发）

如果你的调用链需要走 8000，请按下面填写：
# OpenAI 兼容工具（Codex / OpenCode / Gemini / 多数 IDE 扩展）
OPENAI_BASE_URL=http://localhost:8000/v1
OPENAI_API_KEY=<YOUR_CLI_KEY>

# Claude Code（Anthropic 协议）
# 当前仍建议直连 LiteLLM：
ANTHROPIC_BASE_URL=http://localhost:4000
ANTHROPIC_API_KEY=<YOUR_CLI_KEY>

# 若是远程部署，把 localhost 替换为你的域名：
# OPENAI_BASE_URL=https://ai.your-company.com/v1

Claude Code

Anthropic Claude CLI，支持 opus/sonnet/haiku，完整代码助手
ANTHROPIC_BASE_URL=http://localhost:4000
ANTHROPIC_API_KEY=<YOUR_CLI_KEY>
# 用法示例
claude -p "帮我优化这段代码" --model claude-sonnet-4

OpenAI Codex CLI

OpenAI 官方 Codex CLI，支持 gpt-4o/gpt-4.1 等所有 OpenAI 模型
OPENAI_BASE_URL=http://localhost:8000/v1
OPENAI_API_KEY=<YOUR_CLI_KEY>
# 用法示例
codex "帮我写一个排序算法"

Gemini CLI

Google Gemini CLI（gemini-2.5-pro/flash），OpenAI 兼容模式接入
OPENAI_BASE_URL=http://localhost:8000/v1
OPENAI_API_KEY=<YOUR_CLI_KEY>
# 用法示例（通过 OpenAI 兼容模式）
gemini -p "帮我分析这个日志" -m gemini-2.5-pro

OpenCode

开源代码助手，支持 openai/anthropic/gemini，完整代码上下文理解
OPENAI_BASE_URL=http://localhost:8000/v1
OPENAI_API_KEY=<YOUR_CLI_KEY>
# 用法示例
opencode run "重构这个函数" -m openai/gpt-4.1

Cursor / VS Code（OpenAI 兼容）与 Copilot 说明

注意：GitHub Copilot 官方扩展不支持直接注入第三方 key 来拉取自定义模型列表。
# Cursor Settings → Models → OpenAI API Key
# Base URL: http://localhost:8000/v1
# API Key: <YOUR_CLI_KEY>
#
# VS Code 若使用 OpenAI 兼容插件，可用如下配置：
{
  "openai.apiKey": "<YOUR_CLI_KEY>",
  "openai.baseUrl": "http://localhost:8000/v1"
}

📋 .env 一键配置（所有工具）

将以下内容写入 ~/.env 或 shell profile，所有工具自动使用团队网关
# ===== Team AI Platform CLI 接入配置 =====
# OpenAI 兼容网关（推荐走 8000 转发）
export OPENAI_BASE_URL=http://localhost:8000/v1
export OPENAI_API_KEY=<YOUR_CLI_KEY>

# Claude Code（Anthropic 协议）
export ANTHROPIC_BASE_URL=http://localhost:4000
export ANTHROPIC_API_KEY=<YOUR_CLI_KEY>
# ==========================================
