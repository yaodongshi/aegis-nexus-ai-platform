## 4. 退场流程

### Phase A：隐藏入口

- 从一级导航移除
- 页面加兼容提示

### Phase B：协议降级

- API 响应增加 Deprecated Header
- 文档标注冻结，不再新增特性

### Phase C：正式下线

- 移除前端页面路由
- 删除后端兼容 API
- 提供迁移说明与回滚窗口

## 5. 验收标准

- 主导航不再出现兼容模块入口
- 兼容页面显示降级提示
- 文档存在完整清理矩阵且与主方案一致
